# Christ Church Video Cleanup 1.4.1 - optional login startup

Adds **Start automatically at login** to the Linux and Windows tray dropdowns. Startup is off by default; check the option to enable it and clear it to disable it. Changing the setting leaves current processing running. Opening the app preserves your choice.

- **Ubuntu 24.04 / Debian 13 amd64:** download `ccs-video-cleanup_1.4.1_amd64.deb` and its `.deb.sha256` file. Check with `sha256sum -c`, install with `sudo apt install ./ccs-video-cleanup_1.4.1_amd64.deb`, then run `ccs-video-cleanup setup` as your normal user. Open the updated app once to clear the old implicit startup setting from 1.4.0, then select the tray checkbox if wanted.
- **Windows 10/11 x64:** download `ccs-video-cleanup_1.4.1_windows_x64_setup.exe` and its `.exe.sha256` file. Compare `Get-FileHash` with the checksum before running the installer. Optional login startup runs the tray and server without opening a browser. Updates preserve the setting and uninstall removes it. The installer remains unsigned.
- Updated **Linux and Windows PDF guides** are attached and included in the respective installers. Checksums and validation records are attached too.

Finish processing and quit the tray before upgrading. Saved recordings, analysis and models are preserved. The existing audio/video/podcast workflow is unchanged. Earlier release artifacts remain unchanged and the repository remains private.

## Validation and draft status

All 79 Python tests passed in the source checkout and the installed Ubuntu 24.04 and Debian 13 packages, including synthetic media rendering. All nine browser harnesses passed. The source Linux tray loaded successfully; its checkbox and failure recovery were checked, both startup units remain disabled and the running server was preserved. Windows startup registry behavior was tested with a mock registry; the PowerShell tray parsed successfully and NSIS compiled the installer. Both seven-page guides were rendered and visually checked.

This is a **draft release**. Native Windows 10/11 installation, tray interaction, login-cycle startup, upgrade and uninstall checks for 1.4.1 are still pending because the earlier Windows test VMs are not available. Linux package tests used PRoot userspaces with a shared host kernel; graphical package login cycles were not exercised. Version 1.4.0 remains the recommended tested release until these checks are completed.
