# Version 1.1.0 — recommended Ubuntu/Debian installer

Application-only amd64 installer for Ubuntu 24.04 LTS and Debian 13. APT installs standard dependencies; normal-user setup downloads specialist tools and models separately. No third-party binaries, speech/OCR models or logo are embedded.

Installer: `ccs-video-cleanup_1.1.0_amd64.deb` (1,172,244 bytes).

SHA-256: `02467a35e38fbd618e02ed20fe6a58f07e474131e54a9182a23618845c24f0f8`

Download the `.deb` and `.deb.sha256` sidecar together. From that folder:

```bash
sha256sum -c ccs-video-cleanup_1.1.0_amd64.deb.sha256
```

```bash
sudo apt install ./ccs-video-cleanup_1.1.0_amd64.deb
ccs-video-cleanup setup
```

Run setup without sudo, then launch **Christ Church Video Cleanup**. Internet is required for setup and YouTube downloads; recognition runs locally afterward.

Validation: 19 Python tests, full synthetic render, OCR, offline speech-model loading, repeat setup and web/API checks in proot Ubuntu 24.04/Python 3.12 and Debian 13/Python 3.13. Shared host kernel; desktop login/autostart not exercised. The attached validation JSON identifies this exact installer.
