# Christ Church Video Cleanup 1.4.0 - Linux and Windows

Prepare a sermon for YouTube, a Spotify podcast, or both. Choose the highest available source resolution or a smaller one. Compare three voice-cleanup presets using quiet and louder excerpts, create the selected exports immediately, or tweak and recreate tests until satisfied. Both outputs use the chosen tested audio settings.

## Download and install

- **Ubuntu 24.04 / Debian 13 amd64:** download `ccs-video-cleanup_1.4.0_amd64.deb` and its `.deb.sha256` file. Run `sha256sum -c ccs-video-cleanup_1.4.0_amd64.deb.sha256`, install with `sudo apt install ./ccs-video-cleanup_1.4.0_amd64.deb`, then run `ccs-video-cleanup setup` as your normal user.
- **Windows 10/11 x64:** download `ccs-video-cleanup_1.4.0_windows_x64_setup.exe` and its `.exe.sha256` file. Compare `Get-FileHash` in PowerShell with the checksum, run the installer and open the desktop shortcut. The installer is unsigned; no system Python installation is needed.
- Download the **Linux or Windows illustrated PDF guide** below. Each installer includes its platform guide; Windows adds a Start menu shortcut.

First setup requires internet for local tools/models. Keep the computer awake. Finish work and quit services before updating. Saved jobs and cached models are preserved. Windows uninstall retains user data. Repository access is required for this private church-use release.

## Workflow and background services

The pinned step/task bar stays at the top; sections open for the next action. Fresh launch does not select an old service. Optional tuning is marked Done after the audio is accepted. Saved-service management starts collapsed; individual trash buttons and Delete all require review, acknowledgment and a typed phrase. Deleted jobs go to Trash/Recycle Bin.

Both platforms include a tray icon with current task/progress, Open app and Quit and stop services. Browser closure keeps processing running. Windows uses a native notification-area icon, possibly in hidden-icons overflow, and a kill-on-close job object to stop media children with the server. Linux uses GTK/Ayatana and user systemd; a desktop tray host is required. Active desktop shutdown asks first; CLI processing remains protected.

YouTube exports full-quality H.264/AAC MP4 with the church intro. Spotify exports 48 kHz/128 kbps mono MP3 directly from the same conditioned audio, without title-card silence. Files are validated and offered for manual download; the app does not publish them. Balanced cleanup retains the approved 20 dB suppression / -20 LUFS profile. All speech/OCR/enhancement processing is local.
