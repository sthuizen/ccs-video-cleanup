# Windows 10/11 church edition — v1.2.0

This release makes Christ Church Video Cleanup installable on Windows 10 and Windows 11 x64. It includes the church logo in the interface and intro, a church-symbol desktop/Start menu icon, a standard installer wizard and an included quick-start guide. The existing manual review interface remains available for unusual services.

## Install and run

1. Download `ccs-video-cleanup_1.2.0_windows_x64_setup.exe` and its `.exe.sha256` file. Compare the checksum with `Get-FileHash` in PowerShell.
2. Run the installer, accept the default user folder and click **Install**, then **Finish** with **Open Christ Church Video Cleanup** selected.
3. Keep the PC awake and online during first setup. Approve the official Microsoft C++ prerequisite prompt if it appears. The app prepares the remaining local tools and speech model automatically, with progress and retry controls.
4. On later use, double-click **Christ Church Video Cleanup** on the desktop or in the Start menu. Paste the service URL, review uncertain details and create the finished video.

Use a modern 64-bit Intel/AMD PC, with 8 GB RAM recommended and enough storage for tools, models and videos. No system Python installation, AI account or subscription is needed. The app runs at `http://127.0.0.1:8765`; speech recognition and OCR run locally. Closing the browser leaves processing running. The app does not publish videos.

The installer is unsigned, so Windows may show an unknown-publisher/SmartScreen prompt. First setup needs internet access. If YouTube requests verification, use your own signed-in Firefox session and select `firefox` under **Download access**. The lab's live YouTube request was rate-limited/sign-in blocked; successful authenticated Windows downloading was not claimed.

## Storage, updates and included components

Application files install for the signed-in user under `%LOCALAPPDATA%\Programs\CCSVideoCleanup` by default. Videos, evidence, downloaded tools and models live separately in `%LOCALAPPDATA%\CCSVideoCleanup`. Start menu shortcuts open the data folder, setup log and quick-start instructions. Finish processing before updating or uninstalling. Both operations refuse active work, including command-line processing without a browser server. Uninstall preserves the data folder; reinstall reuses completed setup.

Embedded CPython and pip retain their notices. Specialist Python wheels and the FFmpeg build are hash-pinned; Microsoft C++ is downloaded directly and publisher-signature checked. Downloaded package/model/media notices are retained. Church branding is included for the church's requested private use. The separate `church-logo.png` attachment preserves the authorized raw asset for future builds; keep it subject to the same church-use restrictions.
