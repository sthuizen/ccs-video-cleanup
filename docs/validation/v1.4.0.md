# Version 1.4.0 validation - 11 October 2026

The exact installers and illustrated PDFs are identified by byte size and SHA-256 in [versions.json](../versions.json). Source, installers, checksum sidecars and guides are preserved together in the private release. Synthetic fixtures were used; no service recordings, transcripts, cookies, models or Windows images are published.

## Linux

- Source installation: all 71 Python tests passed; all nine Deno browser harnesses passed. Coverage includes phase-safe audio, full synthetic render/decode, podcast-only and combined exports, audio-selection provenance, tuning/reset, explicit service selection, progress, resolution choice and two-stage library deletion.
- Exact .deb installed in isolated Ubuntu 24.04 and Debian 13 userspaces, followed by normal-user setup. Both passed all 71 tests, offline Whisper model loading, actual RapidOCR initialization and the approved local enhancement profile. Test suites include actual synthetic FFmpeg video and MP3 exports.
- GTK/Ayatana dependencies, packaged tray script/icon, user unit and Linux PDF are included. The existing host GTK tray provides status/progress and shutdown; shared feedback is covered by regression tests.
- These userspaces share the host kernel and do not have graphical logins or systemd as PID 1. Init-only systemd postinstall helpers were bypassed in the PRoot lab where unsupported; graphical package autostart was not claimed. A desktop tray host and user systemd are required for the packaged icon.

## Windows 10 and Windows 11 x64

The exact final installer was installed in actual KVM/QEMU Windows guests (10 build 19045 and 11 build 26100). Each used the previously tested local caches rather than a new empty OS installation.

- Upgrade, active-lock refusal for update/uninstall, desktop shortcut launch, idle uninstall with retained data/models/media and reinstall with reused setup passed on both systems.
- Installed 1.4.0 health/version response, included Windows PDF, Start menu PDF shortcut and native WinForms notification-area icon passed on both systems. Fresh launch reported Ready / No service selected.
- The final installed Python suite passed 71 tests on each Windows platform, with the symlink-only test skipped because the standard lab account lacks symlink privilege (WinError 1314). Path traversal, inventory mutation, expiration and confirmation tests still run.
- All nine Deno browser harnesses passed on both platforms against an isolated source fixture; the installed Windows anonymous-download default was checked separately. Real OCR, offline synthetic speech inference, DeepFilterNet3 enhancement, opposed-stereo rendering, preview decoding, non-ASCII paths, duplicate launch and repeat setup passed.
- With the browser closed, both native trays displayed the synthetic task name, 35% current-file progress, elapsed time and ETA while the server remained available; removing the fixture restored Ready.
- Native Recycle Bin recovery and a child process killed when its job-object parent exited passed on both platforms.
- Native tray Quit was clicked in the visible Windows 11 desktop: the server stopped and relaunch returned one Ready tray. Tooltip/menu feedback includes current task, percentage and elapsed/remaining time. Browser closure is independent of the server. CLI-held locks refuse shutdown; desktop work requires confirmation.

## Guides and limits

Both platform guides have seven pages with actual browser screenshots of a synthetic Example sermon. The Windows guide also shows the native Windows tray menu. All 14 pages were rendered to PNG and visually inspected. Each installer includes the corresponding PDF; separate PDFs are release assets.

The Windows installer is unsigned. No authenticated live YouTube download or actual YouTube/Spotify publication was performed in this release test. Outputs are local files for operator review and manual upload. Upstream network verification/rate limits remain possible. Linux desktop environments without a tray host may hide the icon. Earlier release artifacts and validation records are unchanged.
