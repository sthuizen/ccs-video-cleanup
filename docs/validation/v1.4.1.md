# Version 1.4.1 validation - 12 October 2026

This startup-control candidate is uploaded as a **draft release**. Native Windows validation is pending; version 1.4.0 remains the recommended tested release. Exact installer and guide bytes/SHA-256 are recorded in [versions.json](../versions.json) and [the machine-readable record](v1.4.1.json). Earlier release artifacts are unchanged.

## Linux source and installed packages

- All 79 source Python tests passed, including startup migration, preference persistence, registry mocks, failed-change handling, phase-safe audio, synthetic video rendering and podcast exports. All nine Deno browser harnesses passed.
- The final .deb installed in isolated Ubuntu 24.04 / Python 3.12 and Debian 13 / Python 3.13 userspaces. Both installed packages passed all 79 tests, offline cached Whisper loading and real RapidOCR initialization. Dependencies and model caches were reused; fresh dependency setup was not repeated.
- The source GTK/Ayatana tray reloaded successfully. Its actual GTK toggle callback passed opt-in and failed-change recovery checks with mocked service changes. Legacy implicit startup was reset on the host without stopping either service: the server PID remained 4428 and the tray PID 6228; both units are disabled for login.
- Extracted .deb payloads match the final source tray, startup helper, launcher and setup script; the included Linux guide matches the release guide byte for byte.
- PRoot environments share the host kernel and have no graphical login/systemd PID 1. Graphical packaged login cycles were not exercised. A tray host and user systemd remain required for the packaged startup option.

## Windows build and scope

- NSIS 3.10 compiled the 1.4.1 x64 installer successfully. Its staged launcher, startup helper, tray script and included PDF match the source/release guide.
- Windows startup helper tests use a mock registry: startup initially off, opt-in, opt-out, idempotent removal, quoted paths with spaces, and preservation of unrelated applications' entries passed. The login command includes `--background`.
- The PowerShell tray parsed without errors using PowerShell 7.6.6 on Linux. This does not verify Windows PowerShell 5.1, WinForms, registry operations or actual login behavior.
- Windows 10/11 test VMs used for 1.4.0 are not present in this environment. Native install/upgrade/uninstall, checkbox interaction, login startup without a browser and opt-out login cycles for 1.4.1 remain pending. Follow [Windows testing](../WINDOWS_TESTING.md) before promoting the draft.
- The installer is unsigned. Earlier 1.4.0 native validation is retained as historical evidence, not presented as validation of this patch.

## Guides and privacy

Both updated guides have seven pages. All 14 pages were rendered to PNG and visually inspected, including the new startup instructions. Existing 1.4.0 synthetic screenshots are retained and identified honestly; the Windows tray screenshot predates the new checkbox.

Only source, installers, guides, checksums, quick-start text and sanitized test records are uploaded. No service recordings, transcripts, cookies, models, credentials or Windows VM images are attached. No live authenticated YouTube download or YouTube/Spotify publication was performed.
